# 独立具名局部图输入实验记录（2026-08-02）

## 目标

在豆包 1.6 视觉、基线 Prompt、固定四条训练 Case 不变的前提下，比较三张原图与五张独立具名局部图共同输入是否改善细粒度问题识别。人工标签只用于本地评测，不传给模型。

## 已准备

- 三张原图被标准化为 JPEG，五张局部图按固定角色生成。
- 四条 Case 共生成 12 张原图和 20 张局部图。
- 请求映射、清单和逐条保存的实验运行器已实现。
- 成功标准：人工问题召回 4/4、额外发现少于 17、无证据角色混淆。

## 本轮结果

未运行模型，因此没有可报告的召回率或额外发现数量。

原因是 Coze 手工试运行表单保留此前上传的图片，并在八个图片字段出现动态错位。字段中的文件名无法作为可靠的角色绑定证据。继续点击试运行会污染实验，所以在运行前停止。

## 恢复状态

唯一 Coze 测试副本已恢复三输入基线：Start 和模型节点只保留 `user_image`、`outfit_image`、`generated_image`；临时局部图角色约束已从 Prompt 移除；模型仍为豆包 1.6 视觉，工作流未发布。

## 决策

本实验保持“未执行”，不得记为失败或成功。下一次只能通过可清空输入状态的工作流 API/批处理入口运行；若没有该入口，需要用户允许创建一次性测试副本后再运行。冻结验证集和测试集继续保持未触碰。
