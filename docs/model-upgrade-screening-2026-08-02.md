# 更强视觉模型初筛（2026-08-02）

## 目标

停止继续优化豆包 1.6 的 Prompt 和裁剪输入，改用同一三原图、基线 Prompt 和训练集 Case，验证不同模型家族的专用视觉模型能否带来真实能力升级。人工标签不传给模型，冻结验证集与测试集不运行。

## 候选选择

Coze 中豆包 1.8 深度思考和豆包 2.0 mini 已完成公平测试且问题召回接近零，因此不重复。首个跨模型家族候选选择 `通义千问·VL·Max`，理由是其明确定位为视觉模型，可直接检验当前瓶颈是否仅来自豆包视觉能力。

## 第一条门禁结果

使用已核对的三张原图运行手部训练 Case `6f589d384988d3af0592bfe4`。模型报告了手部问题，但证据同时描述了输入图片中不存在的“深蓝色连帽卫衣”“灰色上衣”“虚化建筑轮廓”等内容，并进一步给出面部、服装、场景多项严重问题。

该输出属于明显视觉证据幻觉，无法作为有效问题召回。按“证据必须对应真实图片”的门禁停止后续样本，不运行第二条和完整 10 条比较集。

## 第二个候选结果

第二个跨模型家族候选为 `GLM 4v`。使用同一手部训练 Case、同一三张原图、同一基线 Prompt 和输出格式运行。模型未发现人工标注的手指/关节轻微瑕疵，四个维度全部给 2 分，并输出 `overall_confidence = 1.0`、`needs_human_review = false`。

该结果没有出现千问式的无关物体描述，但在已知细粒度问题上形成“高置信漏检”，同样没有通过证据门禁，因此不扩展到 10 条比较集。

## 决策与恢复

`通义千问·VL·Max` 与 `GLM 4v` 均不升级。唯一 Coze 测试副本已恢复豆包 1.6 视觉理解-250815、三张原图和基线 Prompt，已自动保存，未发布。

按预设停止条件结束模型枚举：当前没有证据证明新增模型能带来更可靠的细粒度视觉理解，也没有形成可用于模型协作的互补错误证据。系统现阶段定位为人工辅助审核与 badcase 发现工具，不能声称替代人工；不启动多模型投票，不进入冻结验证集和测试集。
