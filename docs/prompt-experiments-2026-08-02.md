# 豆包 1.6 Prompt 平衡实验

## 人工复核结论

- 基线模型产生 17 条人工未记录的额外发现。
- 人工复核后：2 条真实问题、15 条误报，额外发现误报率为 88.2%。
- 真实补充问题为面部五官变形、手指/关节异常。
- 误报集中在轻微五官差异、服装颜色/版型/褶皱、背景元素和手指数目推断。

## Prompt v2 balanced

- 策略：明确正确参考图，排除光照、视角、压缩、遮挡和自然褶皱，收紧证据门槛。
- 训练比较集前 5 条：所有维度 issues 均为空。
- 结果：额外误报被压制，但人工问题召回归零；在已确认面部问题和手部问题上也高置信漏检。
- 结论：不升级。

## Prompt v2.1 targeted

- 策略：限定六类目标标签并要求逐项放大检查，保留误报禁区。
- 前 2 条均包含人工手指/关节问题，模型仍输出空 issues，并以 0.9 confidence 声称人体结构正常。
- 结论：不升级并提前停止，避免继续消耗试跑额度。

## 当前判断

Prompt 能改变模型的报告倾向，但没有证明能提升细粒度图像理解：收紧会导致全漏，放宽会产生大量误报。当前瓶颈更像整图分辨率下的局部视觉信息不足。

下一步保持豆包 1.6 单模型，先测试确定性的局部裁剪/放大输入（脸部、双手、服装 Logo/边缘），再与同一人工标签比较。只有局部输入仍无法提升时，才讨论第二模型复核或模型协作。
